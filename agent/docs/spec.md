# 华为云资源成本洞察与优化Agent - 技术开发文档

## 1. 项目概述

### 1.1 项目定位
华为云资源成本洞察与优化Agent是一款面向中小企业和个人开发者的云成本管理工具，旨在帮助用户快速理解华为云账单构成，智能识别闲置资源，提供可执行的优化建议，实现云成本的有效管控和资源利用率的提升。

### 1.2 核心目标
- **降本增效**：帮助用户识别并削减不必要的云支出
- **资源优化**：提高云资源利用率，避免资源闲置浪费
- **决策支持**：通过可视化分析和智能建议，为用户提供数据驱动的决策依据

### 1.3 目标用户
- 无专职运维团队的中小企业
- 个人开发者
- 云资源成本敏感型用户

### 2.2 功能详细说明

#### 2.2.1 账单上传
- 支持CSV格式的华为云账单文件上传
- 支持文件大小限制（最大10MB）
- 自动解析账单数据字段

**支持的账单类型**：华为云"费用中心 → 账单详情 → 导出"中的**按需计费账单**和**包年包月账单**（流水账单格式暂不支持）。

**CSV 字段映射表**（以华为云导出的标准账单 CSV 为例）：

| CSV 原始列名 | 映射到数据库字段 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- |
| 资源ID | resource_id | 是 | 华为云资源唯一标识 |
| 产品类型 | product_type | 是 | 需标准化映射（如"弹性云服务器"→ ECS，"云硬盘"→ EVS） |
| 产品 | product_name | 否 | 原始产品名称，保留用于展示 |
| 规格 | spec | 否 | 实例规格（如 s6.small.1） |
| 区域 | region | 否 | 云服务区域（如 cn-north-1） |
| 计费模式 | billing_mode | 否 | 按需/包年包月，标准化为 on_demand/monthly/yearly |
| 使用量 | usage | 否 | 用量数值 |
| 使用量单位 | usage_unit | 否 | 如 GB、小时、个 |
| 应付金额 | cost | 是 | 费用金额（元），作为核心分析字段 |
| 账单日期/使用开始时间 | bill_date | 否 | 费用产生的日期，用于趋势分析按日聚合 |

**产品类型标准化映射规则**：

| CSV 原始产品类型 | 标准化类型 |
| :--- | :--- |
| 弹性云服务器 / ECS | ECS |
| 弹性公网IP / EIP | EIP |
| 云硬盘 / EVS | EVS |
| 虚拟私有云 / VPC | VPC |
| 云数据库 / RDS | RDS |
| 对象存储 / OBS | OBS |
| 弹性负载均衡 / ELB | ELB |
| 其他未匹配类型 | OTHER |

#### 2.2.2 费用可视化分析
- **趋势图**：展示费用随时间的变化趋势
- **分类图**：按产品类型（ECS/EIP/EVS/VPC等）展示费用占比
- **区域分析**：按云服务区域展示费用分布
- **实例明细**：展示各资源实例的费用详情

#### 2.2.3 闲置资源诊断

> **数据来源说明**：华为云标准账单 CSV 仅包含计费数据（产品、规格、用量、费用），不包含流量监控数据和 CPU 使用率等性能指标。MVP 阶段的闲置诊断采用以下间接判断策略，基于账单 CSV 可获取的字段进行推断，无需额外对接华为云 Cloud Eye（监控）API。

- **EIP闲置检测**：识别账单中仅有"保有费"而无"流量费/带宽费"的弹性公网IP，判定为闲置（即该 EIP 已分配但未产生实际流量）
- **ECS低负载检测**：识别账单中仅有"实例费/系统盘费"而无"带宽费/流量费"的云服务器，判定为低负载（即该 ECS 可能处于开机但无外部访问的状态）
- **资源利用率报告**：基于上述检测结果，生成整体资源利用率评估

#### 2.2.4 优化建议生成
- **释放建议**：建议释放完全闲置的资源
- **降配建议**：建议将高配低用的ECS降配
- **节省估算**：为每条建议提供预计节省金额
- **操作指引**：提供执行优化操作的步骤说明

| :--- | :--- | :--- | :--- |

## 5.3 数据库设计

### 5.3.1 数据库概述
采用 SQLite 数据库，数据库文件存储在 `data/app.db`。包含以下3张核心表：

### 5.3.2 表结构设计

#### 表1：bills（账单记录）

| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | 自增主键 |
| bill_id | VARCHAR(64) | UNIQUE, NOT NULL | 账单唯一标识，格式：bill-YYYYMMDD-xxxxxxxx |
| file_name | VARCHAR(255) | NOT NULL | 上传的CSV文件名 |
| upload_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 上传时间 |
| record_count | INTEGER | DEFAULT 0 | 解析到的资源记录数 |
| total_amount | FLOAT | DEFAULT 0.0 | 账单总费用 |
| status | VARCHAR(20) | DEFAULT 'pending' | 处理状态：pending/completed/failed |
| error_message | TEXT | NULL | 错误信息（处理失败时记录） |

**索引**：
- `idx_bills_bill_id`：bill_id 唯一索引
- `idx_bills_upload_time`：upload_time 普通索引

---

#### 表2：resources（资源清单）

| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | 自增主键 |
| bill_id | VARCHAR(64) | NOT NULL | 关联的账单ID |
| resource_id | VARCHAR(128) | NOT NULL | 资源唯一标识（华为云资源ID） |
| product_type | VARCHAR(64) | NOT NULL | 标准化产品类型：ECS/EIP/EVS/VPC/RDS/OBS/ELB |
| product_name | VARCHAR(255) | NULL | 原始产品名称（如"弹性云服务器"） |
| spec | VARCHAR(128) | NULL | 实例规格（如 s6.small.1） |
| region | VARCHAR(64) | NULL | 云服务区域（如 cn-north-1） |
| bill_date | DATE | NULL | 账单日期（CSV中的费用产生日期），用于趋势分析按日聚合 |
| cost | FLOAT | DEFAULT 0.0 | 费用金额（元） |
| usage | FLOAT | DEFAULT 0.0 | 用量/使用量 |
| usage_unit | VARCHAR(32) | NULL | 用量单位（如 GB、%、小时） |
| billing_mode | VARCHAR(20) | NULL | 计费模式：on_demand/monthly/yearly |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**索引**：
- `idx_resources_bill_id`：bill_id 普通索引
- `idx_resources_resource_id`：resource_id 普通索引
- `idx_resources_product_type`：product_type 普通索引

---

#### 表3：analysis_results（分析结果/建议）

| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | 自增主键 |
| bill_id | VARCHAR(64) | NOT NULL | 关联的账单ID |
| resource_id | VARCHAR(128) | NOT NULL | 资源ID |
| product_type | VARCHAR(64) | NOT NULL | 产品类型 |
| issue_description | TEXT | NOT NULL | 问题描述（如"仅有保有费，无流量费/带宽费"） |
| recommendation | TEXT | NOT NULL | 操作建议（如"释放该EIP"） |
| estimated_savings | FLOAT | DEFAULT 0.0 | 预计节省金额（元/月） |
| billing_mode | VARCHAR(20) | NULL | 计费模式 |
| risk_level | VARCHAR(20) | DEFAULT 'low' | 风险等级：low/medium/high |
| risk_warning | TEXT | NULL | 风险提示文字 |
| category | VARCHAR(20) | NULL | 建议类型：release/downsize/rightsize/other |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

**索引**：
- `idx_analysis_bill_id`：bill_id 普通索引
- `idx_analysis_resource_id`：resource_id 普通索引
- `idx_analysis_risk_level`：risk_level 普通索引

### 5.3.3 实体关系图

```
bills (账单记录)
    │
    │ 1:N
    ▼
resources (资源清单)
    │
    │ 1:N
    ▼
analysis_results (分析结果)
```

**关系说明**：
- 1个账单（bill）包含多条资源记录（resource）
- 1条资源记录（resource）可对应多条分析建议（analysis_result）

### 6.2 数据处理流程

1. **上传阶段**：用户上传CSV → 后端解析 → 提取字段（资源ID、产品类型、产品、规格、区域、计费模式、使用量、使用量单位、应付金额、账单日期）
2. **存储阶段**：解析后的数据存入SQLite数据库的bills表和resources表
3. **分析阶段**：Pandas从数据库读取数据 → 进行聚合计算 → 生成趋势和分类数据
4. **诊断阶段**：基于账单费用构成间接判断（EIP仅有保有费无流量费 → 闲置；ECS仅有实例费无带宽费 → 低负载）
5. **建议阶段**：根据诊断结果生成优化建议，计算预计节省金额
6. **展示阶段**：前端通过ECharts渲染图表，通过表格展示明细

### 9.1 华为云账单CSV字段说明（预期格式）

> 与 2.2.1 节 CSV 字段映射表一致，以下为华为云导出的标准账单 CSV 中预期包含的字段。

| CSV 原始列名 | 类型 | 说明 |

| 资源ID | String | 华为云资源唯一标识 |

| 规格 | String | 实例规格（如 s6.small.1） |

| 计费模式 | String | 按需/包年包月 |
| 使用量 | Float | 用量数值 |
| 使用量单位 | String | 如 GB、小时、个 |
| 应付金额 | Float | 费用金额（元） |
| 账单日期/使用开始时间 | Date | YYYY-MM-DD格式，费用产生日期 |

### 9.2 诊断规则

- **EIP闲置**：账单中仅有"保有费"而无"流量费/带宽费"，判定为闲置（该 EIP 已分配但未产生实际流量）
- **ECS低负载**：账单中仅有"实例费/系统盘费"而无"带宽费/流量费"，判定为低负载（该 ECS 可能处于开机但无外部访问状态）
